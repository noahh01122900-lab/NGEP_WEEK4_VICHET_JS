# Week 4 — The DOM (2-hour lab)

Topics: what the DOM is, selecting elements (`getElementById`, `querySelector`,
`querySelectorAll`), node properties (`textContent`, `innerHTML`, `getAttribute` /
`setAttribute`, `classList`, `style`), and creating nodes (`createElement`, `append`,
`prepend`, `remove`).

**These exercises run in the browser, not Node** — the DOM only exists inside a browser
(`document` is undefined in plain Node).

## How to run

1. Open `exercises/index.html` directly in your browser (double-click it, or
   right-click → Open with Browser).
2. Open DevTools (F12) → Console tab, to see your `console.log` output and catch errors.
3. Each exercise JS file is already linked with a `<script>` tag at the bottom of
   `index.html` — edit the JS files, save, and refresh the page to see changes.
